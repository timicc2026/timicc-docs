登录后进入控制台面板，左侧选择“API密钥”。

![](/assets/image/QuickStart/004.webp)

### 进入API 密钥

1. 在左侧菜单点击“API密钥”。

![](/assets/image/QuickStart/002.webp)

2. 点击页面上方的“创建密钥”。

![](/assets/image/QuickStart/003.webp)


### 创建密钥

在弹窗中填写密钥信息：

![](/assets/image/QuickStart/005.webp)

- 密钥名称：用于区分不同用途，例如 `Claude Code`、`Codex`。
- 密钥分组：必须选择，分组决定这个密钥可以使用哪些模型。
- 密钥有效期：默认“永不过期”，也可以按需要设置有效期。
- 额度设置：0 = 无限制，密钥实际可用额度仍受账户余额限制。
- IP 限制：不熟悉时建议先保持默认，不要开启模型限制或 IP 白名单。

::: warning 密钥分组一定要选对
密钥分组会直接影响可用模型。比如 Claude Code、Codex 需要选择对应分组；如果分组选错，后续配置 CLI 时很容易出现“模型不存在”或无法调用的问题。

:::

填写完成后，点击右下角“提交”完成创建。

### 查看分组可用模型

你可以在“模型广场”查看每个令牌分组下支持哪些模型。

![](/assets/image/QuickStart/008.webp)

1. 点击页面右上角“模型广场”。
2. 在左侧“可用令牌分组”中选择分组。
3. 右侧模型卡片会显示该分组可用的模型、价格和折扣倍率。
