## 3. 退款政策

### 3.1 退款时效

自订单支付完成之日起超过三十（30）个自然日的订单，需要找客服申请退款。

### 3.2 订阅服务退款

订阅服务的退款以自然周为计算单位。若当前周期内用户已消耗的额度达到或超过该周的限额，则该周视为已完整使用。退款金额的计算公式为：

```text
退款金额 = 订阅实付金额 × (1 - 已使用周数 / 4)
```

### 3.3 充值余额退款（72小时内）

若用户在充值时使用了优惠券，退款时将按原价扣除已使用额度。退款金额的计算公式为：

```text
退款金额 = 实付金额 - (已使用额度 / 优惠券折扣比例:优先消耗充值的) - 5%手续费（stripe官方收取3.4%+0.5刀）
```

说明：由于提前退款导致未满足优惠券的使用条件，优惠券优惠将被撤销，已使用额度按原价计算。

### 3.4 封禁账户

因违反本条款第 4 条（严格禁止的活动）而被封禁的账户，不予退款。

### 3.5 退款受理时间

退款申请将在 3–7 个工作日内处理完成。
